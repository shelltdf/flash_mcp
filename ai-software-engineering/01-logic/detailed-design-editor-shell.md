# 详细设计：编辑器外壳

## 主窗口布局

自上而下：

1. **菜单栏**：文件（新建、打开、保存、发布…）、编辑、视图、插入、修改、控制、帮助（占位）。
2. **工具栏**：选择、手型、缩放、矩形、椭圆、线条、文本、铅笔、画笔、颜料桶、橡皮（MVP 可部分为禁用态）。
3. **中部三列**：左侧 **库**，中央 **舞台 + 选项卡**，右侧 **属性**。
4. **底部**：**时间轴**（可垂直调整高度意图在后续迭代实现）。

## 全局状态

- `activeTool`：当前工具 id。
- `zoom` / `stagePan`：舞台缩放与平移。
- `selection`：当前选中对象 id 列表（占位）。
- `document`：当前文档元数据与打开文件信息。

## 文件 → 打开

用户选择文件后，交由 **文档 IO** 层识别 ZIP/XFL；成功则更新库与时间轴占位数据并刷新 UI。
