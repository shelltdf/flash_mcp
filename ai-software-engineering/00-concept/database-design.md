# 数据库 / 存储设计

本工具以 **浏览器端工程状态** 为主，无强制服务端数据库。

## 内存与序列化

- **当前文档模型**：图层、帧、库条目、舞台对象树等保存在前端状态（如 Pinia store），结构在 `02-physical/flash-editor-web/spec.md` 定义。
- **持久化（可选后续）**：`localStorage` / IndexedDB 保存最近打开路径提示与用户偏好（主题、面板布局），不作为权威工程存储。

## 文件格式

- **XFL / 基于 ZIP 的 FLA**：解压后为 XML + 资源文件；解析结果映射到内部文档模型。
- **SWF**：二进制；播放与发布策略见 `interface-design.md` 与运维文档。
