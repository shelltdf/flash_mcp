# 产品设计：Flash（Animate 精神续作）

## 愿景

在浏览器中提供接近 **Adobe Animate（原 Flash Professional）** 的编辑体验：熟悉的菜单与快捷键、时间轴、舞台、库与属性面板，并逐步支持 **打开 FLA/XFL 工程** 与 **预览或发布 SWF**（在技术可行范围内分阶段落地）。

## 目标用户

- 怀念 Flash 工作流的设计师与动画师。
- 需要在现代环境维护或学习经典二维动画时间轴工具的开发者。

## 范围（MVP → 远期）

| 阶段 | 内容 |
|------|------|
| MVP | 深色主题主窗口；菜单栏/工具栏/库/属性/时间轴/舞台布局；基本帧与图层展示；缩放与手型工具占位 |
| 近期 | 矢量绘制工具（矩形/椭圆/线条/选择）；关键帧插入与简单补间占位 |
| 中期 | **Adobe Animate 工程**：未压缩 **XFL 文件夹**、**ZIP 包**、以及 **PK/ZIP 型 .fla** 的 `DOMDocument.xml` 解析；库与时间轴子集；舞台尺寸与帧率读入 |
| 远期 | **SWF**：集成播放器侧能力（如 Ruffle 嵌入预览）；**发布 SWF** 依赖外部或专用编译管线（浏览器内无法完整复刻 Adobe 编译器） |

## 非目标（当前）

- 与 Adobe Animate 二进制插件生态完全兼容。
- 在纯前端内无外部工具时保证与官方 IDE 完全一致的 SWF 输出。

## UI 几何权威

布局与区域划分以运行中的 Web 客户端为准；概念层不替代 `02-physical/flash-editor-web/` 中的字段级规格。
