# 软件设计

## 子系统

1. **编辑器外壳（Shell）**：菜单、工具栏、可折叠面板、主题与布局状态。
2. **舞台（Stage）**：坐标系、缩放、平移、可选中编辑区（Canvas/SVG 或后续方案）。
3. **时间轴（Timeline）**：图层列表、帧网格、播放头、帧率显示。
4. **库（Library）**：符号与资源树；与打开的工程同步。
5. **属性（Properties）**：当前选中对象或工具的上下文属性。
6. **文档 IO**：打开文件（`.fla` / `.xfl` 相关）；导入 ZIP+XFL；导出与发布流程在物理层细化。

## 与实现对应

默认实现为 `flash/` 下的 Vue 3 + Vite SPA，构建目标见 `02-physical/flash-editor-web/`。
