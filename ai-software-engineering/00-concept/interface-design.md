# 接口设计（程序间）

> 仅描述 API / 文件格式边界 / 未来自动化接口；**不含** GUI 操作细节。

## 文档导入

- **输入**：单文件（`.fla` / `.zip` 等）或 **文件夹**（未压缩 XFL，通过 File System Access 的目录枚举在实现上等价为 `webkitdirectory` 文件列表）。
- **行为**：定位 `DOMDocument.xml`（大小写不敏感）；ZIP 与 **PK 头 `.fla`** 走 JSZip；文件夹走相对路径拼接。解析字段见物理层 `spec.md`。
- **错误语义**：无法识别格式时返回可展示说明（不崩溃）。

## SWF 相关

- **预览**：通过嵌入 **Ruffle** 或等价运行时加载 SWF 字节流（需 CSP 与资源策略配合）；接口为「二进制 URL / Blob → 播放器组件」。
- **发布**：完整 SWF 编译不在本仓库 MVP 保证范围内；若引入外部 CLI，接口为「导出中间表示 → 调用外部进程」仅在桌面/Electron 等环境可行时定义。

## 未来可选 CLI

- `flash-cli open <path>`：打开并校验工程（占位，未实现）。
